ROSLYN CODEX LSP: AGENT REFERENCE
=================================

MCP server: roslyn
MCP tools: diagnostics, navigate, bulk_navigate, symbols (read-only), edit, lsp
Purpose: C# compiler diagnostics, symbol navigation and semantic edits.
Workspace: the agent session's working directory unless configured otherwise.
Source: saved files on disk. Unsaved editor buffers are not available.

CALL FORMAT
-----------
Each tool takes flat arguments. Examples in these files name the tool first:
diagnostics {"file":"src/Calculator.cs"}

Paths are workspace-relative. Inputs and results use one-based lines and
one-based UTF-16 characters, so returned positions can be reused as inputs.
Raw LSP requests keep zero-based coordinates.

Results are compact text lines. Failed calls start with "error CODE: message"
and set isError. Raw LSP results and capabilities are JSON.
An error, incomplete report or truncated result does not establish success.

REFERENCE FILES
---------------
Fetch only the file needed for the task. URLs share this index's directory.

diagnostics.txt - File and glob scans, result fields, limits and verification.
navigation.txt - Definitions, references, call and type hierarchies, hover, symbols, bulk navigation.
edits.txt - Rename and code action preview/apply sequences, stale proposals.
session.txt - Status, capabilities, reload and raw requests.
