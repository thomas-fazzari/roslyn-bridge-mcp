SYMBOL NAVIGATION
=================

Name the symbol, or select a position inside it.

By name:
navigate {"action":"references","symbol":"Calculator.Add"}

symbol matches the end of the fully qualified name: Add, Calculator.Add or
MyApp.Math.Calculator.Add. A parameter list selects an overload: Calculator.Add(int, int).
Generic arguments are optional. When Box and Box<T> both exist, Box.Put names
the non-generic one, and Box<T>.Put the generic one. A parameter type also
matches its nullable form: Add(string) selects Add(string?).
A constructor needs its parameter list: Calculator(ILogger).
Partial declarations in one project count as one symbol. Same-named types in
different projects are separate symbols.

If the name matches several symbols, the error ambiguous_symbol lists up to 20
candidates. Each candidate symbol can be sent back unchanged. When candidates share
a name, send the symbol with the candidate's file. symbol_not_found means no
declaration matched. Use the symbols tool to search by partial name.

By position (file is workspace-relative, line and character are one-based,
character counts UTF-16 code units):
navigate {"action":"definition","file":"src/Calculator.cs","line":12,"character":9}

Replace action with:
type_definition - Find the symbol's type definition.
implementation - Find implementations of an interface or abstract member.
references - Find references, including the declaration.
callers - Find the methods that call this method, with their call sites.
callees - Find the methods this method calls, with the call sites in this file.
supertypes - Find the base types and interfaces of a type.
subtypes - Find the types that derive from or implement a type.
hover - Read type information and documentation.
source - Read the declaration's saved text with its documentation comment.
members - List the members a type declares, across its partial declarations.

source and members also accept a file and a line without a character. They then
use the innermost declaration around that line.

SYMBOL SEARCH
-------------
Document symbols:
symbols {"file":"src/Calculator.cs"}

Workspace symbols:
symbols {"query":"Calculator","limit":50}

For workspace search, omit file. When file is present, query is not used.
Use symbols to locate a declaration, then navigation for semantic relationships.

RESULTS
-------
Results are text lines. Positions are line:character, both one-based, with
UTF-16 characters. Files inside the workspace use relative paths. External and
generated locations keep their absolute URI.

definition, type_definition, implementation and references return one line per file:
src/Foo.cs 42:17 81:9
Location links use the target selection start. limit caps occurrences, not
files. limit defaults to 50 and accepts 1 through 250. A final line starting with
"truncated:" gives the total count. Inspect it before claiming a complete
reference or implementation list. No match returns "no locations".
References leave out source-generated code and end with a line counting the
omitted occurrences. Use the lsp tool with action=request to list them.

callers, callees, supertypes and subtypes return one line per symbol:
src/Consumer.cs:7:26 method MyApp.Consumer.Run(IGreeter)
  calls 7:59
The line gives the declaration position, the kind and then the symbol name.
Send everything after the kind back unchanged as the symbol argument. A result
outside the workspace keeps Roslyn's name. The calls line is present only for
callers and callees. callees lists calls only. A final line counts the
property, field and constant accesses it leaves out.

CONTEXT
-------
Add "context":true to see the trimmed source line of each position without
reading the file:
navigate {"action":"references","symbol":"Calculator.Add","context":true}
Each position then gets its own indented line:
src/Foo.cs
  42:17 var sum = calculator.Add(1, 2);
For callers and callees, the lines are the call sites. Callee call sites are in
the requested file. context uses more tokens, so request it only when needed.

source returns a header per declaration, then its text:
src/Calculator.cs:10-14 method MyApp.Calculator.Add(int, int)
A partial type returns one block per part. When a large type does not fit, a
final "truncated:" line counts the omitted lines. Use members, then source on one
member.

members returns the type, then its members grouped by file, relative to the type:
class MyApp.Calculator
src/Calculator.cs
  12:16 method Add(int, int) : int
Prefix a member with the type name to send it back, as in MyApp.Calculator.Add(int, int).

Symbols use the same line shape. Document symbols omit the file, give the
declaration end after a dash, as in 5:18-9:2, and indent members under their
container. limit counts nested members too. Workspace symbols end with "in CONTAINER".
Hover returns plain text.
Use the lsp tool with action=request for raw LSP locations, full ranges and
location link metadata. Raw results and capabilities are JSON.
